# Program throughput benchmarks (the Architect)

How long `cc_program` takes to deliver, measured end to end on the same request, with what changed between
runs. The benchmark request is small on purpose, so a run exercises every phase (plan, definition of done,
ranks, the Architect's evaluations, the final test cycle, the ladder) in under an hour:

> create a simple command line based calculator that can do basic arithmetic in golang

Each run starts on a fresh, empty directory (`/Users/viren/workspace/github/tmp/calc-bench-N`), on the
`anthropic-standard` profile (Claude on the claude.ai login), with a $40 ceiling. Timings come from the
Conductor execution (task start and end times); costs are the harness's own estimates.
